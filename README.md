PixelSize: ресайз картинок пачками

Сервер на Go, который умеет менять размер изображений параллельно c помощью горутин, задействуя все ядры процессора, а не через цикл for, тобишь по очереди.

Зачем это вообще?

Для более быстрой обработки изображений

Как оно внутри
Вход: Принимает форму с файлами. Я поставил лимиты (не больше 50 штук и не тяжелее 10 МБ каждый). Если убрать лимиты, а уж тем более на размер файла, сервак может тупо не выдержать.
Воркеры: Это ограничитель. Он просто напросто нагружает железо ровно настолько, насколько оно может вывезти..
Выход: Один zip архив со всеми готовыми файлами, ибо это удобно
Стек
Язык: Go модули
Ресайз: Библиотека imaginп ,фильтр Lanczos 
Прочее: Стандартная либа sync, zip
Ограничения 
Файлов: до 50.
Вес одного файла: до 10 МБ.
Размер картинки: до 5000x5000 px.

Как запустить 
Собери: go build -o pixelsize .
Запусти: ./pixelsize
Сервер слушает http://localhost:8080.

Как проверить через терминал:

bash
Копировать
curl -X POST -F "files=@cat.jpg" -F "files=@dog.jpg" -F "width=800" -F "height=600" http://localhost:8080/size --output out.zip
